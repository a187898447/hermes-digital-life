# 人格转译：从女娲 skill 到 SOUL.md

女娲（`huashu-nuwa`）产出的是**思维方式 skill**：它回答"这个人怎么想"，不回答"这个角色怎么说话、和你是谁"。
Hermes 加载人格靠 profile 根目录的 `SOUL.md`。所以中间需要一次**转译**，不是复制粘贴。

## 转译对照

| 女娲 skill 里的部分 | 落到 SOUL.md 的哪一段 | 注意 |
|---|---|---|
| 心智模型、看世界的镜片 | 怎么看世界 | 保留 2–3 个就够，多了系统提示会稀释 |
| 决策启发式 | 遇事怎么判断 | 写成"默认倾向 + 何时例外" |
| 表达 DNA | 表达 DNA | 必须有正反两个例子，否则模型会自己发明语气 |
| 反模式 | 绝对不做 | 女娲常写成"他不做什么"，改写成"你不做什么" |
| 诚实边界 | 诚实边界 | 明确"不知道就说不知道" |
| 核心身份、与用户的关系 | 身份 / 关系与称呼 | 女娲通常没有，需要你补，这是角色感的来源 |
| 安全与平台规则 | 安全边界 | 固定段落，任何人格都不能覆盖 |

## 用法

1. 先用女娲造出人物 skill（`~/.hermes/skills/personas/huashu-nuwa`）。
2. 让 agent 用 `persona-forge` skill 转译：给它女娲 skill 的路径 + 角色名 + 一句关系设定。
3. 产物写到 `~/.hermes/profiles/<角色名>/SOUL.md`（默认 profile 是 `~/.hermes/SOUL.md`），可以直接从本目录的 `SOUL.template.md` 起步。

## 常见坑

- **写成设定集**：外貌、经历、喜好写满两页，模型反而没有行为倾向。SOUL.md 控制在 40–80 行。
- **只有"喜欢什么"，没有"不做什么"**：没有反模式的人格，会顺着用户的话走。
- **没有表达 DNA**：语气是角色最容易崩的部分，必须给例子。
- **把关系设定交给模型编**：默认会变成客服腔，务必写死称呼和亲疏。
