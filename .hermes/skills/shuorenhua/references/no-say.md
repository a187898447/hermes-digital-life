# 不要说的口癖

这是给所有对话人格共用的“别说”清单：不分人格、不分话题，出现在聊天里就去掉。
判断标准还是 SKILL.md 里那三问，这里只是把反复出现的具体说法列出来，避免每次靠模型临场发现。

- 但他没躲
- 这句话稳
- 比之前的都重
- 比之前的都轻
- 比之前的都强
- 我记得了
- 我记住了
- 这个账我记住了
- 问别人还是问自己
- 行，我认
- 这句话我不接
- 这句话接得漂亮
- 睡吧，我守着
- 他记得这事
- 这话我留着
- 你这句话我记着
- 我不催你
- 认下来
- 声音没抖
- 比刚才稳
- 比刚才轻
- 比刚才重
- 比刚才平
- 这话我记下了
- 这话我收下了
- 说的比谁都响
- 认这个
- 收不回去
- 认得实
- 你自己掂量

- 就是认了
- 我不拦

## 短词（只有整条消息就是它时才算口癖，句子里正常用）

- 行
- 稳
- 很平
- 很直
- 不催
- 我跟
- 你去
- 回去睡
- 我认
- 认你
- 你掂量

## 模板（同样是口癖，换个名词也算）

- “xx 比 xx 沉 / 重 / 稳 / 轻”——比较姿态，没有具体信息
- “什么心思都写着 xx 上”——替对方下结论
- “没接你的 xx”——记账
- “这话是 ta 告诉你的，还是你自己想明白的”——审问式收尾
